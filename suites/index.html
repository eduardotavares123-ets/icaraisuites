Acomodações

Suítes pensadas para cada hóspede

O Icaraí Suítes conta com oito suítes amplas, silenciosas e cuidadosamente equipadas para garantir uma estadia confortável — seja você um viajante a trabalho ou a lazer.

Cada suíte oferece cama king size ou configuração com duas camas de solteiro, ar-condicionado inverter, SmartTV, frigobar, cofre para notebook e chuveiro com aquecimento a gás. Tudo o que você precisa para se sentir em casa, com a praticidade de um hotel.
